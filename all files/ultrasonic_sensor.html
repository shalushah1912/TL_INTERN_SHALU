🔊 Ultrasonic Sensor (HC-SR04)

Animated working principle — measuring distance with sound

①
Trigger
MCU sends a 10 μs HIGH pulse on TRIG pin
②
Transmit
Sensor emits 8-cycle burst at 40 kHz
③
Reflect
Sound wave hits object and bounces back
④
Calculate
Time measured → distance computed
Distance (cm)  =  Echo pulse width (μs)  ÷  58
