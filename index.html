Laser Cutting Machine
▼

Learned to operate the laser cutting machine — designing cut files, material preparation, safety protocols, and running precise cuts on acrylic and cardboard.

Complete Workflow Guide

LaserCAD
Step-by-Step

From downloading the software to sending your first job to the laser machine — every step visualised.

Phase 01 — Download & Install
01
Search for LaserCAD Software Install

Open your browser and search for "LaserCAD software" to locate the official Trocen download page. The search suggestions confirm this is a well-known term — look for results pointing to sztrocen.com, the manufacturer's official support portal, to ensure you download the genuine software.

02
Select LaserCAD V8.28.18 from the Downloads List Install

On the Trocen support page, locate the LaserCAD V8.28.18.rar file (circled in green). The page also lists other software such as TroCutCAD, TrocenLaserVision, and TrocenNesting — make sure to pick the correct LaserCAD entry. Click the link to begin the download.

03
Save the Downloaded Archive Install

A "Save As" dialog appears — choose a convenient location such as your Documents folder. The file is named LaserCAD V8.28.18 and will be saved as a Compressed Archive Folder (.rar). After saving, use WinRAR or 7-Zip to extract the contents before proceeding.

04
Run the Setup Executable Install

After extracting the archive, you will find the folder containing AWCCfg, AWCDoc, AWCLanguage, AWCRes sub-folders along with a Setup application (207,484 KB) and a SetupCfg configuration file. Double-click Setup (highlighted by the green arrow) to launch the installer.

05
Select Language in the Welcome Dialog Install

The "Welcome to use" installer dialog opens. You can optionally install the USB Driver first using the top button. Set the Type to LaserCAD and choose your preferred language from the dropdown — English is shown selected here (highlighted in blue). This ensures the software interface will appear in your chosen language.

06
Click the Install Button Install

With the type set to LaserCAD and language confirmed as English, click the Install button (indicated by the green arrow) to begin the installation process. The installer will proceed to ask for a destination path before copying all necessary files to your system.

07
Set the Installation Path Install

The "Select install path" dialog allows you to choose the CorelDraw version compatibility and the destination folder. The default install path is C:\ — you can click Browse to change it. Once satisfied, click OK (shown with the green arrow) to confirm and start the file copy process.

Phase 02 — Interface & Drawing
08
LaserCAD Main Interface Overview Setup

After installation, launch LaserCAD V8.28.7. The main window shows a blank 1200 × 900 mm canvas, a left-side toolbox, a top menu bar, and the Control Panel on the right (with Communication Mode, Layer Options, and Machine Control sections). This is your primary workspace for designing laser cutting and engraving jobs.

09
Select the Ellipse / Shape Tool Design

In the left-side toolbox, locate the Ellipse tool (the oval icon, pointed to by the green arrow). This toolbar contains all the core drawing tools including selection, node editing, line, pencil, bezier, rectangle, ellipse, and text tools. Click the ellipse icon to activate it before drawing on the canvas.

10
Draw an Ellipse on the Canvas Design

Click and drag on the canvas to draw an ellipse. The shape appears in red (indicating it is on the default red layer) and is surrounded by eight selection handles (black squares). The pink cross at the centre marks the object's origin point. You can resize or reposition the ellipse by dragging the handles or moving it with the arrow keys.

11
Select the Text Tool Design

Click the Text tool (the large "A" icon at the bottom of the toolbox, highlighted by the green arrow) to switch to text-input mode. This allows you to add labels, names, or any text to your design — useful for engraving personalised text alongside cut shapes on the laser machine.

12
Enter and Format Text Design

The Edit Text dialog box opens. Type your desired text (e.g., "Prathamesh"), then use the dropdowns to select the font type (TrueType Font), a specific font face (Adobe Heiti Std R), and the font size (8.0). Additional options like Bold, Italic, Underline, X/Y Mirror, Angle, and Serial Number are also available here.

Phase 03 — Layer & Power Settings
13
Assign Layers Using the Colour Bar Setup

At the bottom of the LaserCAD window, a colour palette bar lets you assign selected objects to different layers by clicking a colour swatch. Each colour corresponds to a specific layer with its own speed, power, and work-mode settings. This is how you separate cutting paths from engraving paths in a single job file.

14
Configure Layer Power Parameters Setup

Double-clicking a layer opens the Layer Parameters dialog. Under the Cut(Common) tab, you can set MaxPower and MinPower for up to six laser heads (Power1–Power6). In this example Power1 and Power2 are active at 50% max / 40% min. Adjust these values to match your material's requirements for clean cuts or engravings.

15
Choose the Work Mode for Each Layer Setup

In the Layer Parameters dialog, the Work Mode dropdown (highlighted in green) lets you specify how the laser behaves on that layer. Available modes are Cut, Engrave, Engrave + Cut, Hole, and Pen. Select Cut for through-cuts and Engrave for surface marking at lower power settings.

16
Review All Layers in the Control Panel Setup

The Layer Options panel on the right side of the main window gives a summary of all active layers. Here two layers are configured: the black layer set to Cut at Speed 100 / Power 50, and the blue layer set to Engrave at Speed 180 / Power 30. The checkmarks in the "Out" column confirm both layers will be included when the job is sent to the machine.

Phase 04 — Connect & Send Job
17
Connect to the Laser Machine (USB or Network) Output

In the machine connection settings, select USB Mode and the correct COM port from the list (COM 3, 13, 21, 34, or the AWC controller entries shown). Alternatively, enable Network Mode and enter the machine's IP address (default 192.168.8.8). Click Add (green arrow) if your machine's COM port does not appear in the list yet.

18
Click Download to Send the File Output

In the Machine Control section of the Control Panel, click the Download button (highlighted in green). This triggers the Download Document dialog to open, where you can name your file and configure final transmission options before the job data is transferred to the laser controller's memory.

19
Confirm and Download the Document to the Machine Output

The Download Document dialog shows existing files in the machine's memory on the left. On the right, name the current job (e.g., "dress"), set Work Times and Repeat Delay, and choose optimisation options such as Re-Order Objects. Finally, click the large Download Document button (highlighted in green) to transfer the job — the laser machine is now ready to run.

Electronics — Important Fundamentals
▼

Exploring electronics fundamentals — circuits, components, sensors, and their applications in mechatronics engineering projects. This section will be updated as training progresses.

physical AI

Physical AI combines Artificial Intelligence, Sensors, Processors, Controllers, and Actuators to create intelligent systems that can interact with and operate in the real world. It is a key technology behind modern robotics, autonomous vehicles, smart factories, and intelligent devices.

micro-controller

Definition A Microcontroller (MCU) is a small integrated circuit (IC) that contains a CPU (Central Processing Unit), Memory, and Input/Output (I/O) ports on a single chip. It is designed to control specific tasks in embedded systems and electronic devices.

micro-processor

Definition A Microprocessor is an integrated circuit (IC) that contains only the Central Processing Unit (CPU) of a computer. It performs arithmetic, logical, and control operations according to instructions stored in memory.

differnce between micro-controller and micro-processor

sensor

A sensor is an electronic device that detects or measures a physical quantity (such as temperature, light, pressure, motion, or humidity) and converts it into an electrical signal that can be processed by a microcontroller, microprocessor, or computer.

1.ultrasonic sensor

Ultrasonic Sensor Introduction An Ultrasonic Sensor is an electronic device that measures the distance to an object using high-frequency sound waves (ultrasonic waves). It is commonly used in robotics, automation, obstacle detection, and distance measurement applications.


2.light sensor

A Light Sensor is an electronic device that detects the intensity of light and converts it into an electrical signal. The most commonly used light sensor is the LDR (Light Dependent Resistor), also known as a photoresistor.


3.temperature sensor

A Temperature Sensor is an electronic device that measures temperature and converts it into an electrical signal. It is widely used in industrial automation, weather monitoring, healthcare equipment, and electronic devices.


4.humidity sensor

A Temperature Sensor is an electronic device that measures temperature and converts it into an electrical signal. It is widely used in industrial automation, weather monitoring, healthcare equipment, and electronic devices.

processor

A processor is the central unit of a computer or electronic system that executes instructions, performs calculations, and controls the operation of other components. It is often called the Central Processing Unit (CPU) and is considered the "brain" of a computer.

motors

A motor is an electromechanical device that converts electrical energy into mechanical energy. Motors are widely used in household appliances, industrial machines, robots, electric vehicles, and automation systems.

Actuators

An Actuator is a device that converts electrical, hydraulic, pneumatic, or mechanical energy into physical motion or action. It acts as the output component of a control system and performs the action commanded by a controller or microcontroller.

1 . induction motor

An Induction Motor is an AC electric motor in which electrical current is induced in the rotor by the magnetic field of the stator. It is one of the most widely used motors in industries due to its simple construction, reliability, and low maintenance.


2.AC motor

An AC Motor (Alternating Current Motor) is an electric motor that converts electrical energy into mechanical energy using an alternating current (AC) power supply. AC motors are widely used in homes, industries, and commercial applications because of their reliability, efficiency, and low maintenance.


3. DC motor

A DC (Direct Current) Motor is an electrical machine that converts direct current (DC) electrical energy into mechanical energy. DC motors are widely used in robotics, toys, electric vehicles, conveyor systems, and industrial automation because they provide easy speed control and high starting torque.


4.servo motor

A servo motor is an electric motor designed for precise control of position, speed, and torque. It uses a feedback system (usually a sensor such as an encoder or potentiometer) to monitor its position and correct any error.


5. stepper motor

A stepper motor is an electric motor that rotates in small, precise angular steps rather than continuously like a conventional DC motor.


6. electric motor

An electric motor is a machine that converts electrical energy into mechanical energy (motion) using the interaction between magnetic fields and electric currents.


controller

A controller is an electronic device that manages, directs, and controls the operation of other devices or systems. It receives input signals from sensors, processes the information, and sends output signals to actuators, motors, displays, or other equipment.

1. ESP32

ESP32 is a low-cost, low-power microcontroller developed by Espressif Systems. It is widely used in IoT (Internet of Things) projects .


2.Arduino nano

The Arduino Nano is a small, breadboard-friendly microcontroller board based on the ATmega328P (for the classic version).


3.Arduino uno

Arduino Uno is a popular open-source microcontroller board based on the ATmega328P. It's widely used for electronics, robotics, IoT prototypes, and learning embedded programming.


4.Arduino mega

The Arduino Mega 2560 is a powerful microcontroller board based on the ATmega2560 microcontroller. It is designed for projects that require a large number of input/output pins, memory, and multiple communication ports.
